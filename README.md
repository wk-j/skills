# Skills

A collection of Claude Code skills. Each skill lives in its own top-level directory and is defined by a `SKILL.md` file.

## Skills

| Skill | Purpose | Source |
| --- | --- | --- |
| [analyze-issue](./analyze-issue/SKILL.md) | Analyzes GitHub issues into structured markdown docs (bug/improvement vs question) before any code changes. | Authored in this repo |
| [caveman](./caveman/SKILL.md) | Ultra-compressed communication mode that drops filler, articles, and pleasantries while keeping full technical accuracy. | [mattpocock/skills](https://github.com/mattpocock/skills/tree/main/skills/productivity/caveman) |
| [grill-me](./grill-me/SKILL.md) | Stress-tests a plan by interviewing the user through every decision branch. | [mattpocock/skills](https://github.com/mattpocock/skills/tree/main/grill-me) |
| [karpathy-guidelines](./karpathy-guidelines/SKILL.md) | Coding discipline to curb LLM pitfalls — simplicity, surgical edits, verifiable goals. | [forrestchang/andrej-karpathy-skills](https://github.com/forrestchang/andrej-karpathy-skills/tree/main/skills/karpathy-guidelines) |
| [pretext](./pretext/SKILL.md) | Builds single-file browser demos with `@chenglou/pretext` — text reflowing around obstacles, text-as-geometry games, kinetic typography, ASCII-art layout. | [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent/tree/main/skills/creative/pretext) |
| [post-github-comment](./post-github-comment/SKILL.md) | Posts investigation/answer comments on GitHub issues with AI attribution, labels, and a non-developer-friendly structure. | Authored in this repo |
| [stop-slop](./stop-slop/SKILL.md) | Eliminates predictable AI writing patterns from prose. | [hardikpandya/stop-slop](https://github.com/hardikpandya/stop-slop/tree/main) |
| [to-issues](./to-issues/SKILL.md) | Breaks a plan, spec, or PRD into independently-grabbable GitHub issues using vertical slices. | [mattpocock/skills](https://github.com/mattpocock/skills/tree/main/to-issues) |
| [write-a-skill](./write-a-skill/SKILL.md) | Scaffolds a new skill with proper structure, description triggers, and progressive disclosure. | [mattpocock/skills](https://github.com/mattpocock/skills/tree/main/write-a-skill) |
